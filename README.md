# Henna Artistry

A responsive Flutter website for Henna Artistry, a mehndi artist serving Kochi
and Kottayam, Kerala. The site includes a design gallery, service information,
and WhatsApp and Instagram booking links.

## Run locally

```shell
flutter pub get
flutter run -d chrome
```

## Validate and build

```shell
flutter analyze
flutter test
flutter build web
```

Uploaded design photos are stored in `lib/image/` and registered as Flutter
assets in `pubspec.yaml`.
